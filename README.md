# Student Placement Data Analysis

## Project Overview

This project analyzes student placement data to identify patterns and factors related to student placements.

## Objective

The main objectives of this project are:

- Analyze student placement status
- Study the relationship between academic performance and placement
- Analyze salary trends
- Compare placement rates
- Identify important factors affecting placements

## Tools & Technologies

- Microsoft Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Data Visualization

## Key Analysis

The project includes:

- Data Cleaning
- Exploratory Data Analysis
- Placement Rate Analysis
- Salary Analysis
- Academic Performance Analysis
- Data Visualization

## Conclusion

This project demonstrates basic data cleaning, analysis and visualization skills using a student placement dataset.
